# Open Text Collections #4 
## Hewramî texts

This collection features 15 texts from the Hewramî language, spoken in Hewraman
region of Iranian Kurdistan.

The texts were compiled by Masoud Mohammadirad.
 

The files in this repository contain the texts in the CLDF format. A human readable version of the book is available under the name "Echoes of the past: Hewramî narratives" at https://zenodo.org/records/17140764
